# Vendored skills

Installed from the official Expo skills repository (https://github.com/expo/skills,
MIT, commit a9e5bd3, plugin v1.14.3) for the planned mobile app (see docs/mobile/).
Reviewed before install: instruction files only, plus two local helper scripts
(`expo-ui/scripts/list-components.js`, `eas-workflows/scripts/fetch.js`).
The plugin's remote MCP server (mcp.expo.dev) is deliberately NOT enabled.
Update by re-copying from the upstream repo; do not edit in place.
